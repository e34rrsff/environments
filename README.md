# Environments

This is the beginning of the project.

The scope of this program is to be an interactive CLI app that can use a simple
plain-text file (such as YAML) to create interactive environments.

First use case I'm focusing on is: exams in the form of creating user
environments that will become evaluated after the user interacts with menus or
running a shell (such as Bash).

I will most likely replace the name "Environments" soon, it's just a
placeholder.
